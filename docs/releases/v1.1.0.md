# Pipeworks Dream 1.1.0

Pipeworks now renders actual cylindrical tubes with rounded bends and moving perspective, replacing the flat projected strokes and fixed grid.

## Upgrade guide

Install `pipeworks-dream.apk` over 1.0.0 with `adb -s TV_IP:5555 install -r pipeworks-dream.apk`, or run `firetv-screensavers --install=pipeworks-dream` through Fire TV Toolkit. The package and signing key remain the same. Existing preferences and screensaver selection are retained; no data migration or new permission is needed. Restart the preview or screensaver to load the new renderer. Android 6.0/API 23 and OpenGL ES 2.0 are required. To roll back, uninstall before installing the previous version; Android disallows an ordinary version-code downgrade and uninstalling removes local preferences.

## Breaking changes

None to the settings/provider interface or package identity. Rendering now requires OpenGL ES 2.0; the manifest declares that requirement. Android API 23 remains the minimum. The default image changes substantially because the fixed grid and flat lines are removed.

## Major changes

- Rounded 3D tube meshes, depth occlusion, smooth lighting and metallic highlights.
- Round, square and hexagonal tubes in three thicknesses; individual red, green, blue, purple and gold colors alongside metallic palettes.
- Optional following tails with 5, 15, 30 or 60-second delay, interpolated together with growing heads.
- Smooth growth between engine updates and a slowly drifting perspective camera.
- A visible pre-grown network at startup and GPU-buffered geometry.
- Animated light/dark banners with reduced-motion still versions.

## Minor changes and fixes

- Preserve existing density, speed, finish, background, lighting and glow preferences.
- Stop rendering while the preview or dream is paused.
- Add geometry regression checks for chain separation, cylinder radius, bends, normals and growth bounds.
- Add offline Credits and licenses with project NOTICE and full Apache 2 text, reachable by remote from Settings.
- Correct Toolkit examples to the actual `pipeworks-dream` catalog ID.

## Verification

See [device verification](../VERIFICATION.md) for measured results and limitations. Pure Java tests cover options, path growth, provider values and tube geometry. Privacy and installer checks run separately. Sustained thermal, idle-power, native 4K, and physical Google TV behavior remain unverified.
