# Pipeworks Dream 1.1.1

Start a fresh Preview or Dream session with an empty scene, then visibly grow the
pipes using the existing animation timing. This patch removes startup
prepopulation while retaining all current controls and saved choices.

## Upgrade guide

Upgrade the public 1.1.0/code2 installation by replacing it with the signed
1.1.1/code3 APK. Preserve `com.jeremykenedy.pipeworksdream` and its production
signer. Do not uninstall or clear app data before updating: density, speed,
palette, background, lighting, glow, shape, size, tails, tail delay and
randomization choices must remain.

No configuration migration, permission grant, account, service or TV restart is
needed. Android API23+ and OpenGL ES2.0 requirements are unchanged. For an older
installation, confirm its package and production signer before following the
[1.1.0 upgrade guide](https://github.com/jeremykenedy/pipeworks-dream/blob/v1.1.0/docs/releases/v1.1.0.md).

After replacement, open a fresh Preview and check the empty first frame followed
by pipe growth. Start a new Dream session after a previous session stops. Check
persistent and following tails, then confirm the previous option values remain.
Ordinary Preview pause/resume should retain its current scene.

## Breaking changes

None. Existing defaults, option keys, settings-provider contract, package and
production signer remain. A fresh session now begins empty as intended; the
previous version seeded a visible network before displaying its first frame.

## Major changes

None. This is a compatible startup correction rather than a visual redesign.

## Minor changes and fixes

- Remove the renderer's initial 20 growth steps, or single following-tail step,
  before its first upload. Seed-only geometry is empty; timed worker steps grow
  the first segments normally.
- Create a fresh scene for a new Dream after the previous Dream stopped. Keep
  existing EGL preservation and ordinary Preview pause/resume unchanged.

## Security and data integrity

No new dependency, runtime network access, tracking, permission or preference
write is introduced. Replacement installation retains existing app data. The
production certificate remains
`d496ee9655c19cd60169675f806718bc3094bf8dd4c20a7cf8a74cabb93d0c86`.

## Verification and release gates

Local Java option/mesh tests, 24 installer regression tests, style, privacy, APK
build and signing checks pass. Focused geometry regression covers empty seed
scenes and the first growth step in all cross sections and tail modes.

Native first-frame, growth, lifecycle and preserved-settings checks remain
pending. Screenshots must be captured from the final candidate after those
checks. This source candidate is not a published or visually accepted release.
Do not infer physical TV performance from the local build or geometry checks.

## Rollback and recovery

If startup or playback regresses, stop Preview and select another installed
screensaver while retaining Pipeworks and its app data. Use a verified corrective
APK with a newer version code rather than clearing data or uninstalling merely
to force an Android downgrade. Keep the original per-device installer restoration
backup if system screensaver settings need to be restored. No TV reset is needed.
