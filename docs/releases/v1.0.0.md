# Pipeworks Dream 1.0.0

Initial stable release of the animated pipe-growth screensaver.

## Included

- Continuously growing, segmented pipe paths rendered over a projected 3D grid.
- Adjustable pipe count, growth speed, metal palette, background, lighting, and glow.
- Per-setting random selection and a global randomize-on-start option.
- Android DreamService, remote-friendly settings screen, preview activity, and documented settings provider.
- Guided standalone install/update/uninstall CLI with a checksum-verified release download.

## Compatibility and verification

The app targets API 23 and later. A running Android TV emulator was used to verify installation, settings, preview, and rendering. Fire TV and Google TV physical-device idle activation remain untested; see [device verification](../VERIFICATION.md) and report results in the repository issue tracker.

## Upgrade

Install or update with `python3 install.py --serial TV_IP:5555`. Device settings and screensaver selection are not changed. For a manual download, verify the APK using the checksum file attached to this release:

```bash
shasum -a 256 -c pipeworks-dream.apk.sha256
```

This is the first release. It has no migration steps or breaking changes.
